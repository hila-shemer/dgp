    The keyring lives in this browser only. Clearing site data, a new profile, or a different machine and it is gone. Export it and keep the file somewhere you will still have it.

    The file lists your service and account names in the clear. It is not your seed, so it cannot produce a password — but it does say where you have accounts. Store it accordingly. The exported shape matches the Android and Linux apps, minus the per-entry account override, which only this page understands.

    Your seed is never written down, never sent anywhere, and is gone when this tab closes. This page makes no network requests at all; unplug and it still works.
